## 🌈 Welcome to 2C2A PEGGY!

Welcome to **2C2A PEGGY**, an online store dedicated to making school shopping easy, enjoyable, affordable, and inspiring.

Our goal is to bring together a wide selection of essential school supplies, creative stationery, educational materials, and everyday classroom products in one convenient shopping destination.

Whether you are preparing for a new school year, organizing your workspace, purchasing classroom materials, or discovering creative supplies, 2C2A PEGGY aims to offer everything you need.

We are building a modern shopping experience designed for students, parents, teachers, schools, and creative individuals.

### 🚀 Running the Website Locally

After the storefront files are added to the repository:

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use a local development server if required by the implemented features.

For a static storefront, GitHub Pages may be used to publish the frontend. Dynamic services such as real payment processing require an appropriate backend or an external e-commerce provider.
